# Литературный сборник

Онлайн-архив поэзии и прозы **Эллы Гогелиани** — Flask-приложение, которое отображает
литературные произведения, хранящиеся в виде markdown-файлов.

Все тексты загружаются автоматически из каталога `md_output/`: стихи и проза, включая
вложенные тематические подборки. Контент полностью на русском языке, кодировка — **UTF-8**.

---

## Возможности

- ⚡ **Автоматическая загрузка контента** — все `*.md` файлы из `md_output/поэзия`
  и `md_output/проза` (включая вложенные папки) попадают на сайт без правки кода.
- 📄 **Рендер Markdown в HTML** — тело каждого файла обрабатывается библиотекой
  `python-markdown`, YAML-front matter разбирается (заголовок, автор, дата, теги, описание).
- 🗂 **Разделы и подборки** — произведения группируются по вложенным папкам
  (например, «С вами связана стихами → Зимнее»).
- 🔍 **Поиск** — по названию, автору и тексту произведений (работает с кириллицей).
- 📖 **Детальные страницы** с навигацией «предыдущее / следующее».
- 📱 **Адаптивная вёрстка** на Tailwind CSS, типографика «как в книге» для стихов и прозы.

## Установка и запуск

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить приложение
python app.py
```

Сайт будет доступен по адресу: <http://127.0.0.1:5000>

> Режим отладки включён (`debug=True`), шаблоны перезагружаются автоматически.
> Браузер с сайтом откроется сам. Если порт 5000 занят — приложение выберет
> ближайший свободный порт (5001, 5002, …) и покажет его в консоли.
>
> На Windows удобнее запускать двойным кликом на `start.bat`
> (он установит зависимости и запустит сайт с автозапуском браузера).

## Формат контента (markdown)

Каждый файл в `md_output/` — обычный `.md`-файл в кодировке UTF-8 с YAML-front matter в начале:

```markdown
---
title: "Осенняя элегия"
author:
  - "ЭЛЛА ГОГЕЛИАНИ"
created: "2026-11-14 20:20:00"
description: ""
tags:
  - "clippings"
---

<div style="text-align: center;">Осенняя элегия</div>

<p style="text-indent: 2em;">Прозрачно желтеет береза,</p>
<p style="text-indent: 2em;">Рябин багровеет наряд,</p>
```

### Поля front matter

| Поле         | Тип            | Описание                                |
|--------------|----------------|-----------------------------------------|
| `title`      | строка         | название произведения                   |
| `author`     | строка/список  | автор (по умолчанию «Элла Гогелиани»)   |
| `created`    | строка         | дата создания (`YYYY-MM-DD HH:MM:SS`)   |
| `description`| строка         | аннотация (если есть — берётся для карточки) |
| `tags`       | список         | ключевые слова / рубрики                |

### Как добавить новое произведение

1. Положите `.md`-файл в `md_output/поэзия` (стихи) или `md_output/проза` (проза).
2. При необходимости создайте внутри вложенную папку — она станет отдельной подборкой.
3. Обновите вкладку — произведение появится в списке и поиске автоматически.
   (Список формируется при старте приложения, поэтому в debug-режиме после правок
   сервер перезапустится сам.)

## Самопроверка

```bash
python selftest.py
```

Приложение проверяет:

- рендер **всех** markdown-файлов без ошибок;
- корректные HTTP-статусы всех маршрутов (включая поиск и 404);
- работу формы контактов.

Отчёт печатается в консоль, HTML-сэмплы ключевых страниц сохраняются в `selftest_*.html`
в каталоге проекта (удаляются вручную при необходимости).
